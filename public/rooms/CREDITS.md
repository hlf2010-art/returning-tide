# Shop interiors seen through the windows

360-degree photographs from [Poly Haven](https://polyhaven.com), CC0 (public domain): no
attribution required, credited here anyway. Converted to cube maps by `tools/rooms/make.py`
(their tonemapped JPGs, six 512 px faces per room).

| File | Poly Haven asset | Shown as |
|---|---|---|
| phone_shop.jpg | [Phone Shop](https://polyhaven.com/a/phone_shop) | phones, cameras, opticians, pharmacies; the electronics flagships |
| decor_shop.jpg | [Decor Shop](https://polyhaven.com/a/decor_shop) | shoes, luggage, sports, books |
| witsand_woolshop.jpg | [Witsand Woolshop](https://polyhaven.com/a/witsand_woolshop) | silk and fashion |
| museum_of_ethnography.jpg | [Museum of Ethnography](https://polyhaven.com/a/museum_of_ethnography) | watches, jewellery, arts and crafts, tea, souvenirs |
| comfy_cafe.jpg | [Comfy Café](https://polyhaven.com/a/comfy_cafe) | cafés and pastry shops |
| warm_restaurant.jpg | [Warm Restaurant](https://polyhaven.com/a/warm_restaurant) | restaurants and food halls |
| royal_esplanade.jpg | [Royal Esplanade](https://polyhaven.com/a/royal_esplanade) | department stores |

These are shops elsewhere in the world. 360-degree photos taken inside real Nanjing Road shops
(with the shops' permission) can replace them: put the equirectangular JPEGs in the download
folder under the same names (or add names to `ROOMS` in make.py and `world/shopfronts.js`) and
run the script.
